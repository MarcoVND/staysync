# AGENTS.md — StaySync

## Proyecto
StaySync es una aplicación web dirigida a los hoteles, encargada de gestionar sus reservaciones, habitaciones y locaciones, además de incluir un punto de venta (POS), en este mismo repositorio habrá una carpeta para el frontend y otra para el backend, el código deberá implementar la arquitectura limpia (domain, application, infraestructure y api) además de los principios SOLID

## Tecnologías

### Frontend
- TypeScript
- React con Vite (SPA)
- Vitest + React Testing Library

### Backend
- Python
- FastAPI
- FastAPI Users
- pytest + httpx
- SQLAlchemy
- Alembic
